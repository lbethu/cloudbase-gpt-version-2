# CloudBase AI Architecture Flow

## Version 1

```text
Company Knowledge Sources
→ Document Intake
→ Metadata Classification
→ Sectioning and Chunking
→ Local Retrieval and Ranking
→ Source-Backed Answer
→ Team AI Dashboards
→ Planned Automation Modules
→ Governance and Human Review
```

## Five-layer model

```text
[Knowledge]
COM | SOP | Sales | PM/PL | Field | Technical | RFP | Training | Templates | Standards
        ↓
[Intelligence]
Metadata | Classification | Chunks | Retrieval | Confidence | Citations
        ↓
[Team Guidance]
Sales | Field | PM/PL | Technical | Leadership | New Employees | All Employees
        ↓
[Workflow Automation]
Intake | Checklists | Handoffs | Reviews | Onboarding | Publishing
        ↓
[Governance]
Owners | Approval | Permissions | Versioning | Audit | Review | Retirement
```

## Future state

```text
Approved Real Documents
→ Secure Storage and Connectors
→ Identity and Access Control
→ Extraction and Classification
→ Embeddings and Hybrid Vector Database
→ Permission-Aware Retrieval and Reranking
→ Approved LLM Service
→ Source-Grounded Responses
→ Audit Logs and Quality Monitoring
→ Human Feedback and Review Loop
→ Freshness, Versioning, and Retirement
```

Future integration can use OpenAI, Azure AI, Gemini, or an approved internal LLM service. Provider selection should follow security, data handling, evaluation, and procurement review.
